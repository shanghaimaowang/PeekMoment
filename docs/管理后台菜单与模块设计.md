# PeekMoment 管理后台菜单模块

## 菜单结构

```
数据看板                /dashboard
内容管理
  ├─ 动态管理           /content/moment
  ├─ 评论管理           /content/comment
  └─ 标签话题           /content/tags
审核中心
  ├─ 待审核队列         /moderation/queue
  ├─ 举报处理           /moderation/reports
  └─ 敏感词库           /moderation/sensitive-words
用户管理
  ├─ 用户列表           /users
  └─ 好友关系           /users/friends        P2
统计报表                /statistics
系统管理
  ├─ 操作日志           /system/logs
  ├─ 管理员账号         /system/admins         P2
  ├─ 角色权限           /system/roles          P2
  └─ 系统配置           /system/settings       P2
```

登录页 `/login`、用户详情 `/users/:id`、个人中心 `/profile` 不放进菜单。

## 模块说明

| 模块 | 主要功能 | 优先级 |
| --- | --- | --- |
| 数据看板 | 用户/动态/互动指标，发布趋势，标签和评分分布，待办入口 | P0 |
| 动态管理 | 关键词/作者/标签/时间/状态筛选，媒体预览，下架、删除、置顶 | P0 |
| 评论管理 | 按内容/作者/动态查询，删除、屏蔽、查看上下文 | P1 |
| 标签话题 | 标签增删改、合并、排序、推荐位、使用量统计 | P1 |
| 待审核队列 | 敏感词/举报命中内容，批量通过、驳回并填写原因 | P0 |
| 举报处理 | 查看举报原因和证据，联动下架内容、删除评论、禁用用户 | P1 |
| 敏感词库 | 词条维护、分类、导入导出、命中测试、启用禁用 | P1 |
| 用户列表 | 查询用户，查看详情，禁用/解禁、软删除、查看其内容 | P0 |
| 好友关系 | 好友申请、关系链、拉黑记录处理 | P2 |
| 统计报表 | 内容、用户、互动、审核统计，时间筛选和导出 | P1 |
| 操作日志 | 记录登录、审核、下架、删除、禁用等操作，支持筛选 | P0 |
| 管理员账号 | 后台账号新增、禁用、重置密码 | P2 |
| 角色权限 | RBAC 角色和菜单/按钮权限 | P2 |
| 系统配置 | 内容长度、上传限制、审核开关、公告配置 | P2 |

## 现有 layout 调整

- “首页”改为“数据看板”，路由用 `/dashboard`。
- “发布管理”改为“内容管理”，下设动态、评论、标签。
- 新增“审核中心”“用户管理”“统计报表”“系统管理”分组。
- `el-menu-item` 的 `index` 直接用路由路径，`el-sub-menu` 补上唯一 `index`。
- 恢复路由守卫，未登录跳转 `/login`。

## 落地顺序

1. **P0**：登录、数据看板、用户列表、动态管理、待审核队列、操作日志。
2. **P1**：评论管理、标签话题、举报处理、敏感词库、统计报表。
3. **P2**：管理员账号、角色权限、好友关系、系统配置。
