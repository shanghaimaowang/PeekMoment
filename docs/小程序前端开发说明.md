# PeekMoment 小程序前端

对应分工表的 M2 内容前端和 M6 互动入口。工程位于 `frontend/miniprogram/`，使用 uni-app、Vue 3 和 HBuilderX 工程结构。初版用单设备演示账号「小满」走通内容流程，游客可以浏览、搜索和预览媒体。

## 运行

1. 用 HBuilderX 打开 `frontend/miniprogram`。该目录下能直接看到 `manifest.json`、`pages.json` 和 `main.js`。
2. 在「运行」菜单选择浏览器，可运行 H5。项目使用 HBuilderX 自带的 uni-app 编译环境。
3. 微信端在 `manifest.json` 的微信小程序设置中填写项目自己的 AppID。安装微信开发者工具后，从 HBuilderX 选择「运行到小程序模拟器 → 微信开发者工具」。需要手动导入时，选择生成的 `unpackage/dist/dev/mp-weixin` 目录。
4. 点底部「发布」，使用演示账号登录，完成后会自动回到编辑器。在详情页编辑、删除自己的动态，从「我的」能看到对应变化。

开发时从工程目录启动 H5 或微信小程序。浏览器交互测试使用同一套 Vue 页面和本地业务逻辑，路由、媒体选择和日期控件使用浏览器适配层。微信的胶囊、系统相册和文件权限以开发者工具及真机结果为准。官方运行说明见 [uni-app 快速上手](https://uniapp.dcloud.net.cn/quickstart-hx.html)。

## 页面与操作

| 页面路径 | 主要行为 |
| --- | --- |
| `pages/feed/index` | 按时间倒序展示，顶部切换话题。每批 10 条，触底或点「加载更多」继续。点正文进入详情，点照片放大，点评论直达评论区。 |
| `pages/search/index` | 标题、正文、作者和标签支持关键词匹配，可叠加准确话题和本地日历日期。点击信息流里的标签会带入该话题。 |
| `pages/compose/index` | 标题选填，支持纯文字、最多 9 张图或 1 段视频。可组合内置和自定义标签，最多 5 个。带动态 ID 进入编辑模式。 |
| `pages/detail/index` | 图片浏览、视频播放、1 至 5 星评分、一级评论。重复评分覆盖该用户的上次评分，作者可编辑和确认删除。 |
| `pages/profile/index` | 登录状态、本人动态、收到的评论和评分次数，以及退出入口。 |
| `pages/login/index` | 进入本机演示身份。由发布按钮触发时继续进入发布页，由详情触发时回到原动态。 |

### 第一周联调入口

开发构建的「我的 → 联调广场」从服务器读取动态，每页 10 条。启动服务时为 `PEEK_DEMO_PUBLISH_TOKEN` 设置开发用令牌并启用演示发布身份，启动命令见项目 README。H5 联调还需将 `PEEK_CORS_ORIGIN` 设置为浏览器地址栏中的完整前端源，例如 `http://localhost:5173`。开发机默认连接 `http://127.0.0.1:8080`，真机调试时在 `services/development.js` 调整为真机可达的服务地址，并按微信开发环境配置请求域名。

游客可以直接读列表。在该页输入开发发布令牌，点「写动态」，填写标题、正文或标签并发布，返回后列表自动重新读取。令牌只放在内存中，退出联调广场即清除。该入口本周支持文字与标签，正式文件上传随第二周服务端交付。原有广场、编辑、评分和评论继续使用本机演示数据。

### 附件处理

发布页调用 `PmAttachmentPicker`，可选最多 9 张图或 1 段视频。H5 对 JPEG、PNG 和 WebP 将长边限制在 1600 像素，新文件较小时才采用；GIF 等其他格式保留原文件。微信调用 `uni.compressImage`，质量设为 78。视频由系统选择器压缩。`services/upload.js` 按选择顺序返回媒体引用，同时处理最多 3 项。一次传输失败后最多自动重试 2 次，间隔 250 毫秒和 500 毫秒。压缩失败或重试耗尽时提示出错附件的位置，编辑器保留草稿；再次提交复用已成功的文件。删除附件或离开草稿时会清理已经写入的临时成果。

第一周的默认传输适配器调用 `persist`，目标是本机 IndexedDB 或微信文件目录。真实文件服务就绪后，在 `services/development.js` 的 `uploadPath` 填写同源路径即可为联调发布页开启附件选取。HTTP 适配器用 `uni.uploadFile` 发送 multipart 字段 `file`、`kind` 以及当前开发令牌，预期成功响应为 `{code:0,data:{url:"/uploads/..."}}`；网络故障、HTTP 408、429 和 5xx 进入重试。第二周需与服务端共同核对返回字段及未关联上传文件的回收。

## 接手开发

- `components/PmCard.vue` 负责一条动态的排版与入口；`PmMedia.vue` 展示照片和视频；头像、导航和顶栏由独立组件复用。视觉参考了朋友圈的作者与正文顺序，以及即刻的社区话题入口。首页用细分隔线整理动态，照片沿用发布者自己的内容。示例中用到了日常旅行和校园失物两种不同长度的动态。[即刻界面参考](https://www.yunyingpai.com/product-operation/613254.html)
- `services/store.js` 集中处理列表、筛选、所有权、评分、评论和内容校验。`services/seed.js` 提供三个演示样本。动态的 `id`、`userId` 和评论的 `id` 均按字符串处理；`createdAt`、`at` 在客户端为毫秒时间戳。
- `services/media.js` 分离媒体文件和动态记录。微信分支持久化临时文件，网页分支把 Blob 存进 IndexedDB，在展示时创建对象 URL。元数据写入失败时保留草稿中的文件引用，退出编辑器时回收。编辑保存后再清理移除的旧附件。设备或浏览器清理应用数据后，演示内容会随之清除。
- `services/request.js` 提供 `createRequest(baseUrl, readToken)` 供联调时注入服务地址及令牌。请求支持传入路径、方法和请求体，并区分 HTTP 错误和网络失败。联调广场通过该封装读取列表和发布动态。

### 客户端数据与边界

| 对象 | 本地字段或约束 |
| --- | --- |
| 动态 | `id`、`userId`、`author`、`title`、`body`、`tags`、`media`、`createdAt`、`ratings`、`comments`。 |
| 内容 | 标题最多 40 字，正文最多 1000 字。标题、正文、附件至少填写一项。标签最多 5 个，每个不超过 12 字。 |
| 附件 | 每项为 `{ kind, src }`。图片按展示顺序存储，视频与图片分别发布。正式上传需将端内文件引用替换为服务端可访问的媒体引用。 |
| 评分 | 本地按用户 ID 保存 1 至 5 的整数，列表展示平均值。编辑正文保留原评分与评论。 |
| 评论 | `{ id, userId, author, body, at }`。去除首尾空白后的正文为 1 至 200 字。 |
| 会话 | 演示会话与动态元数据共用 `peekmoment.local.v1`。退出只清除当前身份，再次以同一演示账号登录可以继续编辑自己的动态。 |

### 接口联调分工

| 对接方 | 替换位置 | 需要确认的内容 |
| --- | --- | --- |
| M1 账号与上传 | 登录页、会话读写、媒体服务 | 小程序登录凭证换取会话的请求与响应、会话续期、失效处理、文件大小限制、上传返回的媒体 ID 与 URL。 |
| M3 内容与互动 | 本地内容服务及页面加载方法 | 动态和评论分页、作者字段、媒体顺序、发布时间时区、审核状态、评分汇总与用户自身评分。真实写权限由服务端验证。 |
| M6 互动上传 | 发布页选取媒体、详情页互动 | 附件选择、压缩、传输状态、三路并发和失败重试已接入发布页。二级回复、好友、审核回显属于后续联调。 |

第二周接入正式上传时，需与服务端约定取消、重试和发布失败后的附件回收方式。正式认证、改密和跨设备同步随服务端接口接入。

## 验证记录

| 场景 | 初版结果 |
| --- | --- |
| 游客从广场点发布 | 本地演示登录完成后进入编辑器。 |
| 无标题发图文 | 在浏览器预览实际选择一张照片并发布；刷新详情后照片仍然可见。 |
| 评分和评论 | 选择 4 星、发送一条评论，刷新后保留。修改标题后原评论和评分仍然存在。 |
| 删除与个人列表 | 确认删除测试动态后，广场与个人列表恢复为原有记录。 |
| 搜索 | 点击校园标签后得到 1 条结果；叠加「伞」和不匹配的日期得到 0 条，清除日期恢复为 1 条。 |
| 纯视频发布 | 选择本地 MP4，无标题和正文发布，在详情页读到画面尺寸、时长和播放控件。 |

浏览器交互已验证。当前环境没有 HBuilderX 或微信开发者工具，微信编译、系统相册、胶囊区域布局、文件配额和真机播放仍需在项目环境验证。

第一周新增队列的测试在仓库根目录运行 `node --test frontend/miniprogram/tests/*.test.mjs`。用例覆盖三路并发、附件顺序、单文件自动重试、再次提交复用成功项、编辑器关闭时的在途回收，以及发布和列表的接口契约。微信系统相册和真机持久化需要设备验证。

与 Mock 联调时可在 8080 端口启动 Mock，使用它的公开测试令牌 `mock-publisher`。从仓库根目录运行 `node --test mock/server.test.mjs`，其中的小程序贯通用例会用客户端的真实请求封装向 HTTP Mock 发布内容，再以游客身份读回。

本次在 Edge 浏览器验证了 H5 媒体处理。用生成的 2200 × 1800 像素 JPEG 检查压缩，文件从 1,112,940 字节降至 18,367 字节（1600 × 1309 像素）。经发布页所用队列写入 IndexedDB 后，读回的媒体大小一致，移除后再次读取确认文件已清理。
